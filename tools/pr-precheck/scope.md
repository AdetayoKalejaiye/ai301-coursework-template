# Scope: where your pull request lives, and the rules of the room

## Where your pull request lives

Only pull requests against the course's Path Review repository are in scope:

- Repo: `codepath/pathreview-ai301-fa26-s1`

Your pull request must implement the Unit 3 plan for its issue, on the issue
that plan belongs to. Do not grade work for another repository or issue.

## Path Review house rules

- Open the PR from your own fork's type-prefixed issue branch against `main`.
- Keep one PR per issue and deliver one bounded change.
- Fill every section of Path Review's PR template, including AI disclosure.
- A classmate's PR on a shared issue does not block your own PR.
- Credit attaches to the PR as opened; later review or merge is not part of the
  readiness decision.
